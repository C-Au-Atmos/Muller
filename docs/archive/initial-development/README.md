# 起始开发归档

本目录完整保存 Muller 起始开发阶段的历史资料，包括产品设计、实现路线图、
Stage 2 至 Stage 7.10 的计划与报告、界面设计稿、第三方组件说明和 V0.1.0
发布准备记录。

这些文件反映当时的范围、路径和验收证据，可能包含已经完成、替代或过期的计划。
它们不得直接作为后续版本的开发指令；需要延续的事项应以新的条目 ID 登记到目标
版本的 `01-original-input.md`，重新评审后再进入执行文档。

主要入口：

- [`product-design.md`](product-design.md)：起始产品设计。
- [`implementation-roadmap.md`](implementation-roadmap.md)：阶段实现路线图。
- [`ui-rearchitecture-roadmap.md`](ui-rearchitecture-roadmap.md)：界面重构路线图。
- [`stage-7.10-ux-requirements.md`](stage-7.10-ux-requirements.md)：最后一批阶段需求。
- [`stage-7.10-design-and-delivery-plan.md`](stage-7.10-design-and-delivery-plan.md)：
  最后一批阶段执行计划。
- [`release-readiness.md`](release-readiness.md)：V0.1.0 发布准备记录。
- [`design/`](design/)：历史界面稿和截图。
- [`third-party/`](third-party/)：历史第三方组件说明。
