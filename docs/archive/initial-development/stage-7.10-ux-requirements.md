# Stage 7.10 - Explorer 体验修正与产品化需求

状态：提案，等待进入开发排期  
需求来源：2026-08-06 用户反馈（23 项）  
适用版本：Stage 7.9 之后、Stage 8 之前  
关联设计：[`stage-7.10-design-and-delivery-plan.md`](stage-7.10-design-and-delivery-plan.md)

## 1. 目标

本阶段把 Muller 的文件浏览体验从“功能可用”推进到“符合 Windows 用户预期”。重点是：

- 修复窄窗口布局、Filters 覆盖内容、侧栏误导航和 LS 指示错位等阻断性问题；
- 补齐 Explorer 式地址栏、可见搜索、键入定位、拖放、经典导航栏和右键菜单；
- 建立中英文、主题、字体、密度、音量和动画偏好的统一设置模型；
- 用 Windows Shell 图标、缩略图和语义颜色提高文件及操作的可辨识度；
- 统一 List/Grid/Album/Compare 的选择框、鼠标跟随和键盘弹簧动画；
- 保留现有分页、虚拟化、取消、路径保护、回收站和原子文件操作合同。

## 2. 范围规则

### 2.1 名词

- `工作区标签`：Browse、Duplicates、Compare、Album 等可独立保存路径和历史的标签。
- `系统页面`：Home 与 Settings。它们是单例页面，不属于工作区标签集合。
- `显式新标签动作`：`+`、`Ctrl+T`、中键单击位置、或右键“在新标签页中打开”。
- `徽标`：产品定义的短状态码，如 `LEFT`、`RIGHT`、`KEEP`、`DUP`。徽标不翻译。
- `鼠标跟随框`：指针经过项目时移动的 hover 框；它与已选集合和键盘焦点框是不同状态。

### 2.2 全局约束

- 滚轮、悬停、焦点移动和打开系统页面不得创建工作区标签。
- 所有写操作继续复用现有保护路径、冲突处理、取消、校验和回收站策略。
- 视觉状态不能只依赖颜色；危险、成功、选中和禁用状态还需图标、文本或形状差异。
- `prefers-reduced-motion` 开启时取消弹簧位移，但不得取消焦点、选择和状态反馈。
- UI 在 760x520 至 4K、Windows 100%-200% DPI 下不得出现内容遮挡、不可达控件或文本截断。
- 中文和英文模式下，文件名、路径及用户数据保持原值，不做翻译或大小写改写。

## 4. 详细需求与验收标准

### MUL-UX-001 - Preview 响应式布局

需求：

- Preview 必须参与布局计算，任何宽度下都不能覆盖目录列表、滚动条、上下文菜单或分栏分隔线。
- 以 Browse 内容容器宽度而非整个窗口宽度决定形态：宽屏右侧停靠，中等宽度底部停靠，窄屏进入同区域的 Preview 页面。
- 用户调整的 Preview 宽度仅在右侧停靠形态生效，并在合法范围内恢复。
- 切换形态、关闭 Preview 或切换选择时，不改变目录选择、滚动锚点和活动栏。

验收：760x520、900x700、1360x840、1600x1000 和 4K 截图中，Preview 与列表像素交集为 0；关闭后列表恢复原滚动位置。

### MUL-UX-002 - Filters 非覆盖式面板

需求：

- Filters 在宽屏作为工作区右侧 dock，占用独立 Grid 列；不得使用覆盖内容的绝对定位。
- 中窄宽度下 Filters 作为内容区内的专用页面显示，关闭后返回原目录位置。
- 打开/关闭、切标签和切工作区时保留当前标签的过滤条件，但面板开关是应用级临时状态。
- `Escape` 关闭 Filters；焦点进入面板后必须有可预测的返回点。

验收：Filters 打开时目录内容可见宽度或显示模式明确变化，不存在被面板遮住但仍可点击的项目。

### MUL-UX-003 - 音效音量

需求：

- 默认提示音主观响度明显高于当前版本，并提供 0-100 音量设置；0 等同静音但保留上一次非零值。
- 所有音效经过统一 master gain 和限幅/压缩节点，快速重复操作不得叠加削波。
- 保留当前按声音类型限流以及应用隐藏时不播放的行为。

验收：默认 action/success 峰值至少为当前实现的 2 倍，自动化分析无超出 `[-1, 1]` 的采样，20 次快速 hover 不产生不受限叠音。

### MUL-UX-004 - 侧栏与标签创建规则

需求：

- OW/LS/经典侧栏上的滚轮只滚动或移动视觉候选，不导航、不创建标签。
- 左键位置在当前工作区导航；中键或“在新标签页中打开”才创建标签。
- Home 和 Settings 是单例系统页面，不进入工作区标签数组，不能因关闭/重建产生重复标签。
- 达到标签上限时，显式新标签动作给出反馈，不静默替换现有标签。

验收：连续滚动 100 次并经过 Home，工作区标签数量和活动路径均不变化；显式中键打开位置只增加 1 个标签。

### MUL-UX-005 - 选择内容拖放

需求：

- 从已选项目开始拖动时，载荷包含完整已选集合；从未选项目开始时先把它设为唯一选择。
- Muller 内部支持拖到另一栏、面包屑目录和经典侧栏目录；默认同卷移动、跨卷复制，按住 `Ctrl` 强制复制，按住 `Shift` 强制移动。
- 拖动经过合法目标时显示目标高亮和 Copy/Move 状态；非法、受保护或同源目标显示禁止状态。
- 最终文件操作必须调用现有 transfer/conflict/cancel 安全链路，不新建旁路写接口。
- Windows 外部拖放分两档：本阶段必须支持从 Explorer 拖入 Muller；向 Explorer 拖出作为同阶段原生适配目标，若 Tauri/WebView2 限制阻断则单独形成可交付的 Windows OLE 子项。

验收：单选、多选、同卷、跨卷、冲突、取消、保护路径、拖入和窗口失焦均有原生集成测试；失败后无悬空拖动状态和 staging 残留。

### MUL-UX-006 - 字体与文字亮度

需求：

- 普通 UI 优先使用 Windows 原生 `Segoe UI Variable Text`；路径、数值、徽标和 Diff 使用 `Cascadia Mono/Code`，不可用时回退 `Consolas`。
- 不引用未随应用打包且系统通常不存在的字体作为首选。
- 深色主题主文字接近 Explorer 的高亮白，次要和禁用文字仍保持清晰层级。
- `LEFT`、`RIGHT`、`KEEP`、`DUP` 等徽标保持等宽、全局英文和稳定尺寸。

验收：100%-200% DPI 下中英文不裁切；主、次、弱文字对各自背景的对比度分别不低于 7:1、4.5:1、3:1。

### MUL-UX-007 - 按钮语义颜色

需求：

- 建立 neutral、primary、success、warning、danger 五种按钮语义，不按页面随意指定颜色。
- 删除/回收使用 danger，开始/确认使用 primary，完成/KEEP 使用 success，冲突/警告使用 warning，普通导航保持 neutral。
- Copy/Move、LEFT/RIGHT 等成对操作用图标、方向和文字区分，不只依赖颜色。
- hover、pressed、focus、disabled 在深浅主题均有独立可辨状态。

验收：灰度截图仍能区分危险、禁用和主操作；同一动作在工具栏、菜单与对话框使用同一语义。

### MUL-UX-008 - Explorer 式地址、搜索与键入定位

需求：

- 地址栏默认显示可点击面包屑；每一级路径可直接跳转。点击空白、`Ctrl+L` 或编辑按钮进入文本地址模式，保留现有补全、Enter、Escape 和陈旧请求隔离。
- 地址栏右侧常驻当前活动栏搜索框。`Ctrl+F` 聚焦该框，搜索继续使用完整后端目录会话而非仅已加载行。
- 列表/Grid/Album 获得焦点时，直接输入可打印字符启动滚动前缀缓冲，快速定位下一个匹配名称；超时后重置，重复相同前缀循环匹配。
- 键入定位使用统一弹簧移动焦点框，并以最小滚动量把目标带入视口；输入框、编辑器、重命名和 IME composition 期间不得拦截字符。

验收：可从 `D:\A\B\C` 一次点击返回 A/B/C；100,000 项会话的键入定位在 50ms 内提交目标，未加载目标也可通过后端名称索引定位。

### MUL-UX-009 - 选择框尺寸与边缘

需求：

- List 选择框覆盖行的主要可点击范围，只保留 2-4px 外边距；Grid/Album 与项目视觉边界一致。
- 移除当前左侧粗强调条，改为 1px 均匀边框、低透明填充和明确焦点环。
- 活动选择、非活动栏选择、hover 和键盘焦点四种状态不得互相冒充。

验收：选择框与项目命中区域误差不超过 4px，左右边视觉权重一致。

### MUL-UX-010 - 中文/英文切换

需求：

- Settings 提供 `简体中文` 与 `English`，切换立即生效并持久化；首次启动默认跟随系统语言，非中文系统回退英文。
- 所有可见文本、tooltip、aria-label、空状态、对话框、错误、日期和数量格式均进入国际化资源。
- Rust/Tauri 返回稳定错误码和参数，前端负责翻译；未知错误保留可诊断原文。
- 徽标、品牌、路径、文件名、扩展名和格式名称使用允许列表保持英文。

验收：两种语言分别通过无缺 key 检查；自动化扫描产品 UI 不出现未列入允许列表的中英文混排。

### MUL-UX-011 - Compare/Diff 配色与字体

需求：

- 采用 Codex 类 Diff 语义：新增为低饱和绿色、删除为低饱和红色、修改为分栏红/绿或明确的 before/after，元数据差异为琥珀色，未变内容保持中性。
- 行底色、行号 gutter、行内 mark 和当前差异使用不同层级，不把全部差异压成紫色。
- 文本 Diff 和 CodeMirror Merge 使用同一 token；正文使用 `Cascadia Code/Consolas` 并保持 0 字间距。

验收：色觉模拟与灰度模式仍可分辨新增/删除；Text Diff、Folder Diff、Merge 在深浅主题下语义一致。

### MUL-UX-012 - 深紫高对比与浅色准备

需求：

- 深色主题以近黑紫为底，不使用大面积高饱和紫；通过更亮文字、更清晰边框和多种语义色提高对比。
- 建立语义 token，组件不得新增硬编码主题色；遗留硬编码色需在本阶段迁移。
- 提供 `跟随系统 / 深色 / 浅色` 设置。浅色不是占位表，核心 Browse、Home、Settings、Duplicates、Compare、菜单和对话框均需可用。
- Windows 主题变化时，跟随系统模式无需重启即可更新。

验收：核心界面通过 WCAG AA 对比检查；深浅主题截图不存在不可读文本、透明层脏色或状态丢失。

### MUL-UX-013 - Windows Shell 图标

需求：

- 文件和目录优先显示 Windows Shell 提供的真实图标/缩略图，能反映默认应用、特殊文件夹和系统类型。
- Shell 无结果、超时或格式不支持时回退到当前 Lucide 后缀图标，不显示空白。
- 只为可见窗口和有限 overscan 请求，支持取消、任务代次隔离、内存上限和 DPI 尺寸键。
- 图标服务不得执行文件、加载不可信代码到主 UI 线程或阻塞 Tauri async runtime。

验收：至少覆盖目录、未知文件、EXE、PDF、Office、图片、视频、音频和压缩包；100,000 项滚动请求并发与缓存保持有界。

### MUL-UX-014 - 键盘选择弹簧

需求：

- List、Grid、Album、Duplicates 和 Folder Diff 的方向键/PageUp/PageDown/Home/End 都移动同一焦点框，并使用共享 spring preset。
- 新输入可重定向尚未结束的动画，不排队、不瞬移、不产生多个 RAF。
- 目标不在视口时，焦点框与最小滚动协调完成；不得先跳框再滚动。

验收：连续按键、长按、切栏、resize、切 tab、虚拟化卸载/重入和 reduced motion 矩阵通过。

### MUL-UX-015 - 高密度布局

需求：

- 默认密度减少 Header、地址栏、工具栏、目录栏标题和列表行的垂直占用，导航按钮靠近活动地址。
- Settings 提供 `紧凑 / 标准` 两档；触控热区仍不小于 32x32px，主要鼠标目标建议 36x36px。
- 常用后退、前进、上一级、搜索在窄宽度仍可直接访问；低频设置进入 overflow 或 Settings。

验收：1360x840 下目录内容高度比当前基线增加至少 40px；从列表中心到“上一级”的平均指针距离明显降低且不牺牲命中面积。

### MUL-UX-016 - LS 指示与命中位置一致

需求：

- LS hover/选中效果必须以实际按钮 `getBoundingClientRect()` 为准，不用可能因视觉变换失真的 offset 推导。
- 指针离开、滚动、DPI 改变、侧栏 resize 和虚拟位置更新后立即重算。
- 点击结果必须与指针下可见高亮项一致。

验收：自动化逐项点击中心和边界，视觉高亮与触发 index 始终一致，允许误差不超过 2px。

### MUL-UX-017 - 视频与文件夹缩略图

需求：

- MP4 及系统已安装 handler 支持的视频显示帧缩略图；优先使用 Shell thumbnail provider，失败时使用有界媒体解码回退。
- 文件夹优先使用 Shell 文件夹缩略图；无结果时从最多 4 个符合条件的直接子项合成，不递归遍历。
- 缩略图结果以文件身份、mtime、尺寸、DPI 和主题缓存；目录缓存还包含目录 mtime/内容代次。
- 快速滚动或切目录时取消陈旧任务，大视频和损坏媒体不得导致长时间阻塞或内存持续增长。

验收：真实 MP4、无封面视频、空文件夹、图片文件夹、混合文件夹和损坏媒体均有回退；滚动性能保持现有预算。

### MUL-UX-018 - 右键菜单文件管理扩展

需求：

- 空白区新增 `新建` 子菜单：文件夹、文本文档、空白文件；使用 Explorer 式不冲突默认名称并立即进入重命名。
- 压缩包新增 `解压到当前文件夹`、`解压到同名文件夹`、`选择目标...`；选择项新增 `压缩为 ZIP`。
- 目录背景、目录项和普通文件项新增 `在终端中打开`，文件项以所在目录为工作目录。
- 文件/目录项新增 `复制文件名`；保留单独的 `复制完整路径`，避免语义混淆。
- ZIP 为本阶段必需格式；7z/tar 系列为 Should，RAR 因授权和运行时依赖单列后续，不伪装成已支持。
- 解压必须防 Zip Slip、绝对路径写入、设备名、符号链接逃逸和压缩炸弹，并复用冲突/取消/阶段提交合同。

验收：新建命名冲突、终端路径转义、Unicode 文件名、复制名称、ZIP 正常/损坏/恶意夹具、取消和部分失败均通过。

### MUL-UX-019 - 点击品牌返回 Home

需求：

- `Muller` 品牌标记和文字是一个可聚焦按钮；左键/Enter/Space 打开单例 Home。
- 该操作不创建、关闭或重置工作区标签，也不取消非当前标签拥有的后台任务。

验收：从任意工作区和标签点击 20 次，标签数量不变且 Home 只存在一个系统页面实例。

### MUL-UX-020 - 已选项目上的鼠标跟随动画

需求：

- 鼠标跟随框经过已选项目时继续平滑移动，不因项目已选而卸载。
- 选中底色留在项目上；hover 框作为独立上层轮廓显示，不能覆盖文件名或造成闪白。
- 从空白、未选、已选和跨虚拟化边界进入时使用同一可重定向 spring。

验收：指针连续穿过 20 个混合选中/未选项目时只有一个跟随框，无瞬移、消失或残留。

### MUL-UX-021 - 鼠标跟随延迟设置

需求：

- Settings 提供 `即时 / 轻微 / 柔和 / 自定义`；自定义范围 0-300ms，默认 40ms。
- 延迟只影响跟随框启动，不延迟点击、选择、tooltip、声音和上下文菜单。
- 快速跨越多项时丢弃中间陈旧目标并直接追踪最新目标。

验收：0、40、150、300ms 均有计时测试；设置切换即时生效并持久化。

### MUL-UX-022 - 设置页面与主页减负

需求：

- 新增单例 Settings 系统页面，入口为 Header 齿轮和 `Ctrl+,`。
- 语言、主题、密度、UI scale、侧栏风格、声音开关/音量、动画/跟随延迟移入 Settings。
- Home 与主工具栏不再显示上述持续偏好；视图切换、Filters、分栏、复制/移动等当前任务操作继续留在工作区。
- 设置分为 Appearance、Language、Interaction、Sound 四组，支持恢复默认值。

验收：主页面不再出现偏好型控件；所有迁移设置保留旧用户值并支持键盘完整操作。

### MUL-UX-023 - 经典 Windows 左侧栏

需求：

- 在 OW、LS 之外增加 `Classic`，按树结构显示 Home、固定位置、Known Folders、This PC/驱动器和可展开目录。
- 单击在当前标签导航；双击不额外开标签；中键/右键可显式在新标签打开。
- 展开/折叠与导航分离，展开节点不得改变活动路径；加载子目录可取消且失败只影响该节点。
- 选择位置、焦点、展开状态和滚动位置可恢复；虚拟位置继续使用类型化 target，不伪造文件路径。

验收：重定向 Known Folder、多驱动器、不可读目录、长路径和 UNC 节点行为正确；滚动侧栏不改变当前目录或标签数。

## 5. 非目标与后续项

- Stage 8 的 MFT/USN 全盘索引不纳入本阶段；可见搜索仍是当前目录的非递归搜索。
- 不实现永久删除、无确认覆盖、无复核批量解压或自动执行压缩包内容。
- 首版不承诺 RAR；需要确认可接受的授权、依赖体积和更新策略后另立 issue。
- 文件夹合成缩略图只查看有限直接子项，不递归扫描整个目录树。
- 浅色主题要求核心功能完整，不要求与 Windows Explorer 像素级一致。

## 6. 完成定义

Stage 7.10 只有在以下条件同时满足后才能关闭：

- 23 个原始问题都有对应验收证据或明确拆出的后续 issue；
- lint、TypeScript build、frontend unit、Edge E2E、Rust fmt/clippy/test 和 Tauri release 全部通过；
- 深/浅主题、zh-CN/en-US、紧凑/标准、reduced motion 和关键视口组成的自动化矩阵通过；

- 100%-200% DPI、多显示器和 144Hz 至少完成一次人工验收并记录结果；
- 文档、设置迁移和已知限制与 release 行为一致。
