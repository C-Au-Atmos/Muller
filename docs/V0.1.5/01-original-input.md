## `REQ-0.1.5-002` - Space Sniffer 风格的高性能空间方块视图

### 原始描述

> 类 space sniffer 的需求，space sniffer 软件渲染了文件夹大小的空间方块大小，我希望用一种极高性能的手段去获取空间，然后动态渲染大小，然后方块之间用细的光线以及直角拐弯设计。而且每个方块需要我们的音效事件，以及可以通过方块来打开其中文件夹，继续渲染下一层级等等，还需要有选框高亮。

### 来源与上下文

- 来源：`2026-09-12 用户对话`
- 首次报告时间：`2026-09-12，时区 Asia/Shanghai`
- 使用场景：用户浏览目录时，希望立即看出空间占用比例，并通过空间方块逐层定位大目录和大文件。
- 参考方向：`SpaceSniffer 类 treemap；不复制其品牌视觉或实现细节。`
- 附件：`None`

### 目标体验

- 当前目录及其子树显示为按字节大小缩放的矩形方块；文件夹可继续钻取到下一层级。
- 方块之间使用细的高对比分隔线，分隔线允许直角拐弯，形成稳定的正交视觉秩序。
- 方块支持鼠标、键盘和选框选择；选中项有清晰的边框、填充或路径高亮。
- 方块触发现有音效事件：聚焦、选择、打开、完成扫描和错误状态均可被感知，且连续 hover 不产生音效轰鸣。

### 环境与复现

- 版本/提交：`V0.1.5 需求阶段`
- 系统与硬件：`Windows 桌面版；磁盘类型、目录规模和可用内存尚未提供`
- 前置条件：`用户打开一个可读取的目录`
- 复现步骤：
  1. 打开目录空间视图。
  2. 等待首轮空间统计并观察方块按大小出现或更新。
  3. 选择一个文件夹方块并打开，观察下一层级继续渲染。
  4. 使用鼠标拖拽选框或键盘移动选择，观察高亮与音效反馈。
- 实际结果：`当前产品没有空间方块视图和层级钻取入口。`
- 期望结果：`以低 I/O、可取消、渐进式的目录统计驱动高性能 treemap 渲染；交互、音效和选择状态保持稳定。`

## `REQ-0.1.5-005` - 空间视图方向键、Target Cursor、右键菜单与深黑材质

### 原始描述

> 我很满意，我需要增加一个，方向键选框的功能。
> 然后我需要增加一个可选择特效，就是target cursor。
> 然后对于目前这个不同小文件夹的配色，我需要你再研究一下黑色透亮的效果，配色再丰富一些，目前的灰度层级还不够。不要太白亮了
> 然后我还需要右键菜单，现在右键并不能操作这个文件夹/文件。
> 还有一个点是，我点击为空间视图的时候，我切换左侧栏的文件夹，不应跳回到浏览，而是继续以空间视图显示。

- 来源：2026-09-13 用户对 `0.1.5-beta.2` 的验收反馈。
- 目标：`0.1.5-beta.3`，沿用 `req/0.1.5 -> feat/0.1.5 -> release/0.1.5`，不提升 master。
- 范围：方向键空间选择、可选 Target Cursor、空间 tile 右键菜单、深黑低饱和材质、空间模式下侧栏文件夹导航保持空间视图。

### 验收标准

- 方向键在空间画布获得焦点后按上下左右，按当前可见方块中心的几何邻居移动单选；方向边界保持当前选择；Enter 打开选中的文件夹，Esc 返回上一级。扫描更新或动画过程中仍命中当前帧，焦点不跳回浏览。
- 右键当前帧方块先选中目标，再显示与条目类型匹配的菜单。文件夹支持打开/进入、在浏览器中定位、复制路径、属性；文件支持打开、定位、复制路径、属性，并复用已有复制/剪切、重命名、回收站等安全操作。汇总块先显示可访问成员入口，不把虚拟汇总当真实文件操作。菜单外点击关闭，键盘 Escape 关闭。
- 菜单执行沿用现有文件操作和确认语义，成功后使当前空间快照失效或重新扫描，避免继续显示旧目录大小。
- 设置增加 Target Cursor `system/target` 可选项，默认 system；持久化、重启恢复、按钮/菜单项和 Canvas 当前方块可锁定，不能覆盖原生拖拽/输入编辑；touch、减少动画、窗口失焦/隐藏和卸载时清理并恢复系统光标。第三方 React Bits 源代码改为项目 TypeScript/CSS 形式，保留依赖和归属说明。
- 空间方块采用深黑透亮分层，增加低饱和墨蓝、石墨、烟紫、青黑、暖黑等细差和局部反光；整体不使用大面积白灰，白色只用于细线、文本和选中直角。
- 已处于空间视图时，从左侧栏选择新文件夹不改变 `activeTool`；取消旧扫描、启动新目录空间扫描，旧会话不能覆盖新目录，切回浏览按钮后才进入浏览。

### 评审结论

- 结论：`Accepted`，优先级 P1，纳入 `0.1.5-beta.3`。
- 风险：Canvas 没有 DOM 子节点，Target Cursor 需要当前帧 hit-test 注册；右键破坏性操作需复用既有确认；方向键不能干扰可编辑控件；深色对比需保留可读文本和 WCAG 级焦点。
- 验证：新增 SpaceSniffer 单元测试、设置持久化测试、右键菜单和键盘/侧栏 Edge E2E；运行完整 lint/test/build、Rust gates 与 Edge suite。

### 执行计划

- T01：SpaceSniffer 建立键盘邻居选择、右键目标/菜单状态、Canvas 当前帧 Target Cursor surface 注册和菜单关闭/操作回调。
- T02：App/Explorer 传递空间操作回调，复用 `fileOperationsClient`，导航后失效或重扫；侧栏 QuickLocation 保留 `space` 模式。
- T03：Preferences/Settings 加入 `cursorEffect`，Target Cursor 在全局 portal 中按设置挂载并支持 system/reduced/touch 生命周期。
- T04：SpaceSniffer.css 与 Canvas palette 使用深黑透亮低饱和层级，增加可测试颜色/对比契约。
- T05：自动化回归和 beta.3 EXE，保留 beta.2/manifest/hash 供追溯。

### 用户补充反馈（2026-09-13，REQ-0.1.5-005）

> 右键菜单需要和浏览页面大部分功能一致，除了比较、双栏；较小项目列表需要和主浏览页面选框一致，可选中、操作和右键；右侧栏目可以调整宽度；空间页面集成清理指示；Target 只在空间视图使用，文件夹框使用亮白色四角边框。
