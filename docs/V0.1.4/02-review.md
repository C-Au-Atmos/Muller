## `REQ-0.1.4-001` - 自定义关键词收纳文件

### 评审输入

- 原始输入：[`01-original-input.md#req-0-1-4-001`](01-original-input.md#req-0-1-4-001)
- 评审日期：`2026-09-02`
- 参与人：`Codex`
- 当前结论：`Accepted`
- 优先级：`P1`
- 目标版本或重审条件：`V0.1.4`

### 价值与范围判断

- 用户价值：用一次关键词操作完成跨子目录的文件集中，减少手工拖拽和遗漏。
- 问题影响：当前功能缺失；批量移动涉及数据风险，必须可观察、可恢复。
- 当前版本范围：`In scope`：新建文件夹时可选自动收纳；右键目录触发自定义吸取；
  关键词匹配、冲突保护、失败反馈、最近一次收纳撤销。
- 非目标：不移动目录；不扫描目标目录子树；不覆盖现有文件；不提供跨磁盘批量
  事务回滚或跨应用持久化的撤销历史。
- 依赖与阻塞：依赖现有 Tauri 文件操作和目录刷新机制；无外部服务依赖。

### 技术评审

- 建议技术栈：React/TypeScript 表单与状态；Rust/Tauri 递归扫描和受保护移动；
  复用 `TransferReport` 与任务取消机制。
- 预计改动模块：`BrowseWorkspace`、文件操作客户端、`src-tauri/src/file_operations.rs`、
  Tauri 命令注册、本地化、相关单元和 Edge E2E 测试。
- 数据或接口变更：增加关键词收纳和收纳撤销命令；返回每项实际目标路径与失败项，
  使 keep-both 结果可准确撤销。
- 性能与资源影响：扫描和移动在线程池执行；只保留待移动路径与最近一次撤销记录，
  不读取文件内容，不额外建立全盘索引。
- 安全与文件操作风险：目录路径由 Rust 校验；跳过符号链接；目标目录及子树排除；
  冲突使用 keep-both；撤销使用 fail，原位置被占用时不覆盖。
- 测试策略：Rust 临时目录测试递归匹配、排除目标、冲突和撤销；客户端契约测试；
  Edge E2E 测试两种入口、状态反馈和 Ctrl+Z。
- 替代方案：纯前端逐项调用现有移动命令会重复扫描、难以处理目标目录排除和批量
  撤销，因此采用一个 Rust 批量命令并复用既有单项受保护移动。

### 版本决策

- 是否延期：`No`
- 决策理由：需求边界可在现有浏览和文件操作架构内实现，且恢复失败时可保留原
  结果并提示用户，风险可控。
- 验收条件：
  - [ ] 新建文件夹时可填写关键词并选择自动收纳；相关文件递归移动到新目录。
  - [ ] 右键目录可触发自定义吸取；目标目录自身及子树不被扫描或移动。
  - [ ] 已存在同名文件不被覆盖，失败项留在原位置并显示数量。
  - [ ] 收纳成功后 `Ctrl+Z` 恢复最近一次成功移动项；原位置冲突时不覆盖并反馈失败。
  - [ ] 无匹配文件时不报错，不创建额外移动记录。

## `REQ-0.1.4-002` - 上一级和下一级 Windows 快捷键

### 评审输入

- 原始输入：[`01-original-input.md#req-0-1-4-002`](01-original-input.md#req-0-1-4-002)
- 评审日期：`2026-09-02`
- 参与人：`Codex`
- 当前结论：`Accepted`
- 优先级：`P2`
- 目标版本或重审条件：`V0.1.4`

### 价值与范围判断

- 用户价值：匹配 Windows 文件管理器操作习惯，降低目录历史导航成本。
- 问题影响：当前活动栏缺少对应键位；已有鼠标按钮和命令入口不受影响。
- 当前版本范围：`In scope`：`Alt+左箭头` 后退、`Alt+右箭头` 前进，并保持按钮、
  命令面板和现有标签排序行为可用。
- 非目标：不改变目录历史算法；不把快捷键用于系统级全局热键；不在文本编辑、
  菜单和对话框中抢占按键。
- 依赖与阻塞：依赖现有 `BrowseWorkspaceHandle` 和 `CompareWorkspaceHandle` 导航 API。

### 技术评审

- 建议技术栈：复用 React 全局键盘命令解析器和现有导航 handle。
- 预计改动模块：`src/commands/appCommands.ts`、`App.tsx`、键盘映射单元测试及 E2E。
- 数据或接口变更：增加后退和前进应用命令，不改变文件或持久化数据格式。
- 性能与资源影响：单次键盘事件处理，无可观测额外开销。
- 安全与文件操作风险：快捷键只改变当前视图位置，不修改文件。
- 测试策略：命令映射单元测试；Edge E2E 验证目录历史变化及无历史时不变。
- 替代方案：仅给地址栏按钮增加 title 无法满足键盘操作需求，因此采用应用级命令映射。

### 版本决策

- 是否延期：`No`
- 决策理由：改动范围小，依赖现有导航能力，且无需新增持久化状态。
- 验收条件：
  - [ ] `Alt+左箭头` 调用活动浏览或比较栏的后退。
  - [ ] `Alt+右箭头` 调用活动浏览或比较栏的前进。
  - [ ] 文本输入、菜单和对话框中的按键行为不被抢占。
  - [ ] 现有工作区标签的 Alt+箭头排序行为不退化。
